# pymongo-api

## Как запустить

Запускаем mongodb и приложение

```shell
docker compose up -d
```

Настраиваем шардирование с репликацией и заполняем базу данных сгенерированными записями в количестве 20000

```shell
./scripts/setting-sharding-replication.sh
```

## Как проверить

### Проверить общую статистику по шардированию

Открыть в браузере http://localhost:8080

### Проверить отдельно статистику по каждому шарду

```shell
./scripts/shards-status.sh
```
